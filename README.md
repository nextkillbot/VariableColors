# Okay? How do I even edit these colors for my own personal stuff

1) Just clone my repository into your own, on the main menu, click the green button that says "Code"
2) There'll be a dropdown, just download it as a .zip file
3) Head over to your Downloads folder, go to `my-theme.less` and read the comment notes. Read it very carefully or else idk what will happen `¯\_(ツ)_/¯`
4) Make sure you're signed in to GitHub, since if you wanna use it, you'll have to edit `package.json`
